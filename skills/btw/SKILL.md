# /btw 侧信道问答

在对话中临时问一个「旁路问题」时使用。等价于 Claude Code 的 /btw。

## 用法

```
/btw <问题>
```

例如：`/btw 我们刚才决定用哪个动画压缩格式？`

## 行为

- **看到上下文**：问题能看到当前会话已发生的一切（用户与助手往来）
- **不落盘**：问题与回答都不写入会话记录，主对话无感知
- **无工具**：回答只来自已有上下文，不会去读文件、跑命令、联网

## 适合

- 回想之前的决策、约定、命名
- 确认讨论中提到的概念
- 检查进行中的工作进度
- 快速知识校验（如语法细节）

## 不适合

- 需要读取未读文件的问题（上下文里没有的内容答不了）
- 需要联网/搜索的问题
